# Auto Sale Workflow - Odoo 19

Automate your sales operations: Delivery, Invoice, and Payment — all in one click!

## Features

- **Auto Confirm and Validate**: Automatically confirm and validate sales orders
- **Auto Invoice Generation**: Choose automatic invoice creation options
- **Validate Invoice**: Option to validate invoices automatically
- **Auto Register Payment**: Automatically register payments
- **Shipping/Invoice Policy**: Configure policies per order
- **Sale/Payment Journal**: Select journals per order

## Installation

1. Copy the `auto_sale_workflow` folder to your Odoo addons directory
2. Restart Odoo server
3. Update Apps List (in Odoo, go to Apps > Update Apps List)
4. Search for "Auto Sale Workflow"
5. Click Install

## Configuration

1. Go to **Sales > Configuration > Settings**
2. Find the **Automatic Sales Process** section
3. Enable desired features:
   - Auto Validate Delivery
   - Auto Sale Invoice (with options)

## Usage

1. Create a Sales Order
2. (Optional) Enable Auto Workflow in the order's Auto Workflow tab
3. Configure specific settings if needed
4. Click Confirm
5. Watch the automation happen!
